# TFE4146 — Halvlederkomponenter

Interaktiv studieguide for [TFE4146](https://www.ntnu.no/studier/emner/TFE4146)
ved NTNU: **[halvleder.martinsundal.no](https://halvleder.martinsundal.no)** — moduler med quiz, flashcards,
formelsamling og begreper.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
