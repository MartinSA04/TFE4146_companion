# TFE4146 Halvlederkomponenter

Interaktivt kompendium i [TFE4146](https://www.ntnu.no/studier/emner/TFE4146) ved NTNU:
moduler med quiz, flashcards, formelsamling og begreper. Les det på
**[halvleder.martinsundal.no](https://halvleder.martinsundal.no)**.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
